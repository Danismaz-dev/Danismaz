☁️ Google Sheets Bulut Bağlantısı

Tüm telefonların ve bilgisayarların aynı Google E-Tablo'ya anlık bağlanması için Google Apps Script Web Uygulaması URL'nizi buraya yapıştırın.

3 Adımda URL Alma:

  1. Google E-Tablonuzda: Uzantılar -> Apps Script açıp Code.gs kodunu yapıştırın.
  2. Dağıt -> Yeni Dağıtım -> Web Uygulaması seçin.
  3. Erişimi: "Herkes" (Anyone) yapıp Dağıt deyin ve verilen Web App URL'sini buraya yapıştırın.
